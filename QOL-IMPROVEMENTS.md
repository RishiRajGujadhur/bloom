# Quality-of-life improvements

This checklist tracks a focused refresh across the requested Bloom workflows.
Items are intentionally small enough to review and verify independently.

## To-dos

- [x] Add a keyboard shortcut to focus the task composer.
- [x] Show an at-a-glance open, due-today, and completed summary.
- [x] Add one-tap task completion undo.
- [x] Add a clear empty-search state with a reset action.
- [x] Provide a compact task-density toggle.
- [x] Allow sorting tasks by due date, priority, or creation order.

## Daybook modes

- [x] Add search across saved page titles and text.
- [x] Add a visible word-count goal while writing.
- [x] Make save status persistent and easy to scan.
- [x] Add accessible labels to saved-page quick actions.
- [x] Offer a clear recovery action after deleting a page.
- [x] Add a compact view of recent writing activity.

## Urges

- [x] Add a clear empty state with a direct habit-creation path.
- [x] Make intensity selection announce the selected value accessibly.
- [x] Add a quick retry action after logging an urge.
- [x] Show recent logging history without entering patterns.
- [x] Add stronger confirmation feedback after a log is saved.
- [x] Persist the last selected urge-tracker view.
