# Ambient demo stems

These ten mono PCM WAV files are original synthesized demo sounds generated by
`scripts/generate-ambient.mjs`. They contain no external samples or recordings.
The instrument and environment names describe approximations, not recorded
instruments, sonatas, or human crowds. Replace the paths in `src/types/audio.ts`
with licensed production stems when available.

Each loop is 12 seconds at 22.05 kHz with an overlapping seam and conservative
peak headroom. Total decoded mono sample memory is approximately 10.6 MB. WAV
avoids MP3 encoder padding for Web Audio loops. Browser HTML audio fallback may
still introduce loop gaps; sample-accurate musical synchronization is not provided.

Playback starts only after pressing Play. Selecting presets while paused is
silent. Closing the panel or navigating does not stop playback; use Pause.
The provider unloads only its own Howls when unmounted, leaving RPG sounds alone.
